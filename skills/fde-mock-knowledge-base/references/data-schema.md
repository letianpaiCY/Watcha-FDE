# 知识文档结构与资产范围

固定创建 5 篇美妆零售文档和 1 篇索引。

文档范围包括：商品标签、库存效期、功效咨询、客诉退换和不良反应。

每篇文档包含适用角色、版本、生效日期、负责人、权限等级、规则、例外、人工升级、不适用范围和公开来源。内容为课程用模拟企业知识，不构成专业意见。

资产中不包含测试问题、预期答案和通过标签。

## 学员项目与验收边界

学员基于这些文档构建知识检索与问答工具。工具输出至少应包含用户问题、实际答案、引用的知识文档及原文位置、是否需要人工确认。学员可以只完成知识检索，也可以继续生成客服回复或设计转人工流程。

测试题集可以包含“知识库问题、预期答案、实际答案”三个核心字段，并覆盖商品信息、成分功效、库存效期、退换货和不良反应。学员自行结合业务风险确定阈值；参考标准为整体答案准确率达到 80% 以上，且没有编造信息或遗漏必须转人工的高风险问题。

本 Skill 只创建原始知识文档，不创建上述测试题集，也不替学员计算准确率或给出验收结论。
