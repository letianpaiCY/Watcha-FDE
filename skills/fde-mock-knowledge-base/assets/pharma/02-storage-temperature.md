# 药品储存、温湿度与效期管理规范

> 模拟企业知识文档。依据公开监管资料整理，不代表真实仓库作业指导书。

## 文档信息

- 适用角色：仓储人员、养护人员、质量管理员
- 版本：V3.1
- 生效日期：2026-03-01
- 内容负责人：仓储质量部
- 权限等级：企业内部

## 储存条件

药品按包装标示或批准文件规定的温度储存。没有明确温度要求时，应按适用药典和企业制度执行。模拟仓库相对湿度控制范围为 35%-75%，任何超限都需要记录持续时间和受影响区域。

## 状态与分区

合格药品、待判定药品和不合格药品应通过区域或系统状态明确区分。待判定和不合格药品不得销售。破损、泄漏或疑似质量问题的药品立即隔离并通知质量管理人员。

## 效期管理

库存按先到期先出管理，定期检查账货一致性和近效期情况。系统提醒只能辅助养护，不能自动修改有效期、质量状态或解除锁定。

## 例外与人工升级

温湿度监测中断、超限时间不明、冷藏设备故障、药品状态与系统不一致时，停止相关出库并转质量人员评估。工具不得仅凭恢复后的正常温度认定药品质量未受影响。

## 不适用范围

本文不提供具体药品的储存温度和稳定性结论，必须以药品包装和批准资料为准。
